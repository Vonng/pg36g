## 概览

本章不追求 SQL 大全，而是基于你在 ch01 已搭好的 Pigsty 沙箱，建立一张可操作的 PostgreSQL 全局地图：你连到了谁、对象怎么分层、改动如何回滚、权限如何封边界。

## 章节定位

用一个最小业务案例把 PostgreSQL 的对象层级、读写路径和权限边界串起来，为 ch03 的 `psql` 与工具链学习提供上下文。

## 学习完成标准

- 能确认当前连接的实例、数据库、用户与会话上下文。
- 能解释并定位 `集群 -> 数据库 -> 模式 -> 表` 四层关系。
- 能跑通 `todo_app` 主线案例：建表、写入、查询、回滚。
- 能用系统目录查询业务对象元信息。
- 能创建并验证只读角色的最小权限闭环。

## 内容边界

### 本章要讲什么

- 连接上下文与操作落点
- 四层对象地图
- 主线案例闭环
- 事务回滚与改动可逆
- 系统目录的对象可观测
- 最小权限模型
- 扩展能力边界

### 本章明确不讲什么

- 完整 SQL 教程
- 深入内核实现细节
- 运维专题（HA/备份/监控）
- 工具大全与横向评测

## 主线与支线

- 主线案例：`todo_app`（单表任务管理）
- 支线案例：`reporter` 只读角色验证
